This is an example post. To write a new one, copy this file in `src/content/blog/`, rename it (the file name becomes the web address, e.g. `my-first-job.md` → `/blog/my-first-job`), and change the details between the `---` lines at the top.

## Formatting

Write in plain text. A few symbols add formatting:

- `## Heading` makes a heading
- `**bold**` makes **bold** text
- `[link text](https://example.com)` makes a link
- `![description](/images/photo.webp)` adds a picture from `public/images/`

Delete this post when you no longer need it.
